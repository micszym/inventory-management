System Architecture

Factory Inventory Management System

A full-stack inventory and operations demo: a Vue 3 single-page application backed by a Python FastAPI service that serves in-memory mock data loaded from JSON files. No database — all state lives in process memory for the lifetime of the server.

Frontend · localhost:3000 Backend · localhost:8001 API docs · /docs
Overview

Three-tier architecture

The system separates cleanly into a presentation layer (Vue SPA), an application layer (FastAPI REST service), and a data layer (JSON files loaded into memory). Communication between the browser and server is plain HTTP/JSON over the REST API, with filters passed as query parameters.

Request Lifecycle

Data flow

A single user action — for example, selecting a warehouse in the filter bar — propagates through the entire stack and back. The same four filters (Time Period, Warehouse, Category, Order Status) drive every data view.

User adjusts a filter
The shared useFilters composable holds the selected warehouse, category, status, and month as reactive refs. A change triggers a reload in the active view.
View calls the API client
The view passes the current filters to a method in api.js, which builds a URLSearchParams query string — skipping any filter set to all.
axios sends an HTTP request
A GET request goes to the FastAPI service, e.g. GET /api/orders?warehouse=East&status=processing.
FastAPI filters in memory
The endpoint runs apply_filters() (warehouse / category / status) and filter_by_month() (direct month or quarter mapping) over the in-memory Python lists.
Pydantic validates the response
Results are serialized through typed models (response_model), guaranteeing a consistent JSON shape back to the client.
Vue renders reactively
The response is stored in refs (e.g. allOrders, inventoryItems); computed properties derive totals and chart data, and the template re-renders automatically.
Interface

REST API endpoints

All endpoints are namespaced under /api. Filterable endpoints accept optional query parameters; omitting a parameter (or passing all) returns the unfiltered set.

MethodPathPurpose / Filters
GET/api/inventoryInventory items · warehouse, category
GET/api/inventory/{id}Single inventory item (404 if missing)

GET/api/orders/{id}Single order (404 if missing)
